generated for Sheffield.

# 2. Field Definitions

## Scenario

  -----------------------------------------------------------------------
  Field                   Type                    Description
  ----------------------- ----------------------- -----------------------
  scenario_id             string                  Unique scenario
                                                  identifier

  name                    string                  Human-readable scenario
                                                  name

  category                string                  Disaster type

  seed                    integer                 Random seed used for
                                                  generation
  -----------------------------------------------------------------------

## Ambulance

  -----------------------------------------------------------------------
  Field                   Type                    Description
  ----------------------- ----------------------- -----------------------
  id                      string                  Ambulance identifier

  lat                     float                   Latitude

  lon                     float                   Longitude

  status                  string                  Current status
  -----------------------------------------------------------------------

## Incident

  -----------------------------------------------------------------------
  Field                   Type                    Description
  ----------------------- ----------------------- -----------------------
  id                      string                  Incident identifier

  lat                     float                   Latitude

  lon                     float                   Longitude

  severity_level          string                  LOW / MEDIUM / HIGH /
                                                  CRITICAL

  severity_weight         integer                 Numerical priority
                                                  weight
  -----------------------------------------------------------------------

## Hospital

  -----------------------------------------------------------------------
  Field                   Type                    Description
  ----------------------- ----------------------- -----------------------
  id                      string                  Hospital identifier

  name                    string                  Hospital name

  lat                     float                   Latitude

  lon                     float                   Longitude

  capacity                integer                 Total hospital capacity

  available_beds          integer                 Current available beds
  -----------------------------------------------------------------------

# 3. Distance Matrix Output

Purpose:

Provide ambulance-to-incident travel distances for optimisation
algorithms.

Generated by:

    build_distance_matrix(scenario)

## Example

    {
      "A1": {
        "I1": 2.61,
        "I2": 10.85,
        "I3": 18.67
      },

      "A2": {
        "I1": 3.90,
        "I2": 10.45,
        "I3": 16.43
      },

      "A3": {
        "I1": 3.35,
        "I2": 11.49,
        "I3": 20.54
      }
    }

Interpretation:

    distance_matrix["A1"]["I2"]

returns the travel distance between Ambulance A1 and Incident I2.

# 4. Severity Mapping

Purpose:

Provide incident priorities to optimisation algorithms.

## Example

    {
      "I1": 25,
      "I2": 50,
      "I3": 75
    }

Severity Scale:

    LOW      = 25
    MEDIUM   = 50
    HIGH     = 75
    CRITICAL = 100

# 5. Future Hospital Routing Matrix

Planned for Week 2.

Purpose:

Provide incident-to-hospital transport costs.

## Example

    {
      "I1": {
        "H1": 3.4,
        "H2": 1.7
      },

      "I2": {
        "H1": 2.8,
        "H2": 4.2
      }
    }

Interpretation:

    hospital_matrix["I1"]["H2"]

returns transport distance from Incident I1 to Hospital H2.

# 6. Usage by Team Members

## Member 1 (Quantum Optimisation)

Consumes:

-   Scenario Object
-   Distance Matrix
-   Severity Weights

Uses data to:

-   Generate decision variables
-   Construct QUBO
-   Execute QAOA optimisation

## Member 3 (Dashboard)

Consumes:

-   Scenario Object
-   Classical Results
-   Quantum Results

Uses data to:

-   Render Sheffield map
-   Display ambulances
-   Display incidents
-   Display hospitals
-   Visualise optimisation assignments

## Member 4 (Integration & Classical Optimisation)

Consumes:

-   Scenario Object
-   Distance Matrix
-   Severity Weights

Uses data to:

-   Execute classical optimisation baseline
-   Compare against quantum results
-   Integrate all modules

# 7. Notes

1.  IDs should remain string-based throughout the project.

Examples:

    A1
    A2
    A3

    I1
    I2
    I3

    H1
    H2
    H3

2.  Distance matrices should contain raw distances only.

3.  Severity weights should remain separate from distances.

4.  Objective functions should be implemented inside the optimisation
    modules rather than inside the simulation engine.

5.  The simulation engine is responsible for generating realistic
    disaster scenarios and optimisation-ready datasets only.
